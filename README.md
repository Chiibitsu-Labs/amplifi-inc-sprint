## The system in one breath

```
CORPUS  →  feeds the WORKFLOW  →  produces CONSISTENT OUTPUT  →  measured by the INSTRUMENT
   ↑___________ the improve skill writes learnings back ___________↓
```

The instrument reads the whole system. High rework routes to the corpus fix,
not to a hire. Hire is the last branch, on purpose.

## Scope discipline

Core Build = **analyst function only**. Marketing and product were guided-DIY
in-session; their full builds are a future engagement. The git migration of
the corpus is deliberately-not-yet (CTO blocker) ~ Drive is the bridge, and
the scaffold is structured so the move is a copy-paste, not a rebuild.
